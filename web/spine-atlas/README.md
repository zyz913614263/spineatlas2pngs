# Spine 图集拆图

在浏览器里按 Spine 的 `.atlas` 描述，把一张打好包的图集 PNG 拆成独立图片，或导出成分层 PSD。不上传文件，也不运行 See-through 的扩散模型。

## 打开

在这个目录启动本地页面：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。

直接双击 `index.html` 也可以下载 ZIP 和 PSD。写入本地文件夹需要通过上面的地址用 Chrome 或 Edge 打开。

## 使用

1. 选择图集 PNG（打包后的大图）。
2. 选择同一次导出的 `.atlas` 文本。不要选骨架 `.json`。
3. 右侧会列出区域。两边都选好之后，预览里画出每个区域，并给出拆开的缩略图。
4. 导出：
   - **下载文件夹（ZIP）**：每个部件一张 PNG
   - **下载 PSD**：每个部件一层，按它在图集上的位置摆放
   - **写入本地文件夹**：把 PNG 写进你选的目录

可选：

- **还原打包时裁掉的透明边**：按 atlas 里的 `offsets` / `orig` 把部件放回裁切前的画布。
- **取消预乘透明**：图集标了 `pma: true` 时会自动勾上。

可以先点「载入示例」，确认旋转 90° 的部件会转回原来的方向。

## 坐标和限制

区域的 `xy` / `bounds` 从图片左上角算起。`rotate: true` 或 `90` 表示这块图在图集里逆时针转了 90°，导出时会转回去。也支持 180° 和 270°。

只有图集描述时，图层不会按骨架的 setup pose 拼回角色。那份位置在 `.json` 或 `.skel` 里，这个页面不读骨架。

## 文件

| 文件 | 作用 |
|------|------|
| `index.html` | 页面 |
| `app.js` | 解析 atlas、拆图、生成 PSD 和 ZIP |
| `ui.js` | 选择文件和预览 |
